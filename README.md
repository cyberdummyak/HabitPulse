# ⚡ HabitPulse — Planilla Inteligente de Hábitos, Estudio y Pendientes

Aplicación web interactiva de productividad personal en un solo archivo (`index.html`), diseñada para seguimiento semanal de hábitos, estudio de Diplomado, búsqueda de trabajo y gestión de tareas no rutinarias.

## ✨ Características Principales
- **🗓️ Matriz Semanal Multi-Estado**: Marca hábitos al 100% (`✓`) o en versión Mínimo Viable (`⚡` 50%) para días de baja energía.
- **🛡️ Escudos de Racha Inteligentes**: Soporte por columna para **🍕 Cheat Day**, **✈️ Día de Viaje** y **🤒 Día de Salud / Imprevisto**.
- **⏱️ Temporizador Pomodoro Integrado**: Sesiones de 25m / 45m que marcan automáticamente tu avance del Diplomado.
- **📌 Gestor de Tareas No Rutinarias**: Grupos 100% editables (`✈️ Viajes`, `🩺 Salud`, `💼 Carrera`), sub-notas y **Top 3 Foco de Hoy**.
- **🎨 3 Temas Visuales**: Modo Oscuro Pro, Modo Claro y **Tema Códice Mate** con fondo animado en `<canvas>`.
- **💾 Privacidad Total**: Todos tus datos se guardan localmente en tu navegador (`localStorage`) con exportación e importación en formato `.json`.

## 🚀 Cómo usar
1. Abre el enlace de **GitHub Pages** de este repositorio o haz doble clic sobre `index.html` en tu computador.
2. Usa el botón **Kit GitHub / Datos** arriba a la derecha para descargar o restaurar copias de seguridad (`.json`).
